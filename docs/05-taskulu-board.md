# برد مدیریت کار پروژه

برای بخش مدیریت کار پروژه، این برد را می‌توان در تسکولو (یا ابزار مشابه) ایجاد کرد. هدف این است که سابقه انجام پروژه به‌صورت مرحله‌ای و قابل ارائه باشد.

## ستون‌ها

1. Backlog
2. هفته اول
3. هفته دوم
4. هفته سوم
5. هفته چهارم
6. Done

## کارت‌های پروژه

### هفته اول
- DB-01 — طراحی جداول User، Letter و Attachment
- BE-01 — ساخت FastAPI و اتصال SQLAlchemy به PostgreSQL
- DEV-01 — ساخت Dockerfileهای backend، frontend و database
- DOC-01 — رسم Class Diagram و Architecture Diagram

### هفته دوم
- BE-02 — پیاده‌سازی هش رمز عبور
- BE-03 — پیاده‌سازی Login و JWT
- FE-01 — طراحی صفحه Login
- FE-02 — ارسال JWT در درخواست‌های API

### هفته سوم
- BE-04 — پیاده‌سازی ارسال نامه
- BE-05 — پیاده‌سازی Inbox و Sent
- BE-06 — پیاده‌سازی پیوست و دانلود
- FE-03 — ساخت فرم ارسال نامه
- FE-04 — نمایش کارتابل‌ها

### هفته چهارم
- QA-01 — تست ورود موفق و ناموفق
- QA-02 — تست ارسال، دریافت و پیوست
- DOC-02 — تکمیل README
- DOC-03 — آماده‌سازی سناریوی ارائه

## وضعیت نهایی

تمام کارت‌های بالا در نسخه فعلی پروژه پیاده‌سازی شده‌اند. برای ارائه، بهتر است کارت‌ها در ابزار مدیریت کار به‌ترتیب هفته‌ها ثبت شوند و در صورت نیاز تصویر برد نیز به مستندات تحویل اضافه شود.

## نکته مهم

این فایل جایگزین خود ابزار مدیریت کار نیست؛ بلکه محتوای آماده برای ساخت برد را فراهم می‌کند. اگر استاد الزام کرده باشد که حتماً تصویر برد از تسکولو ارائه شود، باید همین کارت‌ها در حساب تسکولو ساخته و از برد نهایی Screenshot تهیه شود.
