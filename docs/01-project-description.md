# شرح پروژه

هدف پروژه ساخت یک سامانه ساده مدیریت نامه است. هر کاربر بعد از ورود می‌تواند یک نامه برای کاربر دیگر بفرستد. نامه شامل موضوع، متن و یک فایل اختیاری است. هر کاربر فقط نامه‌های مربوط به خودش را می‌بیند.

## بخش‌های پروژه

### فرانت‌اند

فایل‌های `index.html`، `styles.css` و `app.js` صفحه ورود، فرم ارسال نامه و فهرست نامه‌ها را تشکیل می‌دهند. درخواست‌های فرانت‌اند با `fetch` به API فرستاده می‌شوند.

### بک‌اند

FastAPI ورود کاربران، ساخت توکن، ثبت نامه، دریافت نامه‌ها و دانلود پیوست را انجام می‌دهد. SQLAlchemy برای ارتباط با دیتابیس استفاده شده است.

### دیتابیس

سه جدول اصلی وجود دارد:

- `users` برای اطلاعات کاربران
- `letters` برای موضوع، متن، فرستنده، گیرنده و وضعیت خوانده‌شدن
- `attachments` برای اطلاعات فایل پیوست

فایل واقعی پیوست داخل پوشه Upload ذخیره می‌شود و فقط اطلاعات آن در دیتابیس قرار می‌گیرد.

## روند ورود

کاربر نام کاربری و رمز عبور را وارد می‌کند. بک‌اند رمز واردشده را با هش ذخیره‌شده مقایسه می‌کند. بعد از ورود موفق، یک JWT برگردانده می‌شود. فرانت‌اند این توکن را در درخواست‌های بعدی داخل هدر Authorization می‌فرستد.

## روند ارسال نامه

فرانت‌اند شناسه گیرنده، موضوع، متن و فایل را ارسال می‌کند. بک‌اند فرستنده را از توکن پیدا می‌کند. بعد از بررسی اطلاعات، نامه در دیتابیس و فایل در Volume ذخیره می‌شود.

## کنترل دسترسی

جزئیات نامه و پیوست فقط برای فرستنده یا گیرنده قابل مشاهده است. شناسه فرستنده از فرم دریافت نمی‌شود تا کاربر نتواند نام شخص دیگری را به عنوان فرستنده ثبت کند.
